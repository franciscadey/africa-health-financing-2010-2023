# Upload the reviewed project to GitHub

Suggested repository name: `africa-health-financing-2010-2023`.

1. Extract the project ZIP and open the folder inside it. Keep this complete copy locally, including the original workbook and verification files.
2. Sign in to GitHub and create a new repository. Choose its visibility. Leave the options to add a README, .gitignore and license unchecked because the project already has a README and .gitignore; the author still needs to select a code license.
3. Use Add file → Upload files. Upload the contents of the project folder, not the outer ZIP or its enclosing folder.
4. For a browser upload, omit the XLSX files in data/raw and data/verification unless you deliberately decide to include them with the required attribution. Browser uploads do not apply the local .gitignore automatically. Keep each folder's README and the comparison CSVs. The public notebook requires the source workbook to rerun; the README explains how to supply it.
5. Commit the files with a message such as “Add reproduced capstone analysis and WDI verification”.
6. Check that the README images display and open `notebooks/africa_health_financing_executed.ipynb` to inspect its saved outputs.

Choose the project code license before inviting reuse. The source-consistency checks and clean execution are complete; the report still records interpretation limits, unknown original acquisition provenance and the unexplained geographic selection. Do not describe the model estimates as causal.
